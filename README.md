# resQ – Animal Rescue Web App

resQ is a simple web app that helps people report injured or distressed stray animals and connects them with rescue teams.

 ## Features
 
- Report animals with photo
- Share location
- Add description
- Rescue team notification
- Track rescue status
## Tech Stack
- Python (Flask)
- HTML, CSS
## Setup

- git clone [https://github.com/k-kathiresan/resQ.git](https://github.com/K-Kathiresan/resQ-A-Voice-for-the-Voiceless)

- cd resQ
- pip install flask
- python app.py

##  Goal

To make animal rescue faster and more accessible.
